# Rust-Inspired S&box Solo Survival Gamemode

Open-source solo survival gamemode for S&box, inspired by Facepunch's Rust. Not affiliated with Facepunch.

## Features

- First-person player movement
- Solo play for offline/local experiences
- Modular for future inventory, gathering, building, etc.

## Getting Started

1. Clone this repo into your S&box add-ons directory.
2. Launch S&box in dev mode.
3. Select this gamemode.
